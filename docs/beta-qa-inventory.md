# Проверка beta: ежедневники, карточка филиала и обзор сети

Проверка только на localhost с синтетическими пользователями и филиалами.
Боевые данные и доступы не используются в снимках.

| Возможность | Проверка |
|---|---|
| Окно заполнения по роли | РМ явно задаёт окно, версию и основание; РФ не видит редактор |
| Личная запись по дате | Создать запись РФ; сменить роль на РОП; записи различаются |
| Автосохранение | Ввод текста, ожидание сохранения, перезагрузка с восстановлением |
| Ошибка сохранения | Отклонить запрос; текст остаётся, автоматического цикла повторов нет |
| Сдача и проверка | Все поля обязательны; сдача переводит на проверку, РМ принимает |
| Связи с задачами | API: идемпотентная ссылка, неизменяемая версия, атомарный откат |
| Карточка филиала | Паспорт, роль просмотра, дневные записи, переход в запись |
| Обзор сети | Серверные счётчики, доступные филиалы, честное отсутствие KPI |
| Разграничение | API: чужой филиал, отозванная роль, отсутствие сессии |
| Вне окна | API: нельзя создать/изменить/сдать запись; нет частичной записи |
| Размеры и темы | Desktop 1440, mobile 390; светлая/тёмная темы, отсутствие переполнения |

Этот список не является заявлением о полном покрытии ТЗ. Расписание обязательного заполнения, полный бизнес-каталог ежедневников и публикация KPI остаются отдельными этапами.
