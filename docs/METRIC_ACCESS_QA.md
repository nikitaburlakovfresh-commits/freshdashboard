# Проверки управления допусками к метрикам

Локальная синтетическая PostgreSQL 16, не production.

## Инвентарь приёмки

- API: отсутствие автоматических прав, текущая личная сессия, отдельное NETWORK
  permission, Origin/CSRF, закрытая форма команды, отсутствие секретов в ответах.
- Выдача: явные метрики, один реальный филиал, срок внутри назначения,
  отсутствие самовыдачи, запрет перезаписи действующего допуска.
- Отзыв: немедленное прекращение чтения, возможность отозвать допуск
  неактивного пользователя, повторная выдача только новым подтверждением.
- Проверка: без изменения прав, привязка к actor/состоянию, 10 минут,
  конкурирующие проверки, повторная отправка, журнал и атомарный откат.
- Публикация: только существующий bootstrap и staging, отдельный другой
  уполномоченный actor; собственный PUBLISH через интерфейс не выдаётся.
- Первичная настройка администратора: только явная операторская команда,
  singleton bootstrap, аудит, отказ от скрытой повторной выдачи.
- Интерфейс: выдача → проверка → отмена; выдача → подтверждение → история;
  отзыв, сброс проверки после правки, запрещённый пользователь,
  срок действия, ошибки сервера; desktop/mobile, светлая/тёмная тема.

Полный аудит безопасности и приёмка на боевой базе этим не заменяются.

## Результат

- 22 новые серверные интеграционные проверки пройдены; реальная локальная
  PostgreSQL, без подмены хранилища. 336 прежних серверных проверок также
  пройдены по отдельным группам; всего 358.
- 48 существующих клиентских тестов пройдены (`npx tsx --test client/tests/*.test.ts`).
- Сборки сервера и клиента успешны; `git diff --check` без ошибок.
- Playwright: выдача READ двух метрик реального по структуре, но синтетического
  филиала; отмена без записи; подтверждение и история; отзыв; правка основания
  сбрасывает preview; у RF без административного права формы нет.
- Проверены desktop 1440×1000, mobile 375×900, светлая и тёмная темы,
  ширина документа 375px при viewport 375px; ошибок pageerror нет.
- Исправлены выбор демонстрационных филиалов (сервер и ранее запрещал их)
  и конфликт стилей primary-кнопки. Повторно проверен цвет кнопки:
  фон rgb(0,61,255), текст rgb(255,255,255).

Браузерный сценарий для PUBLISH не выполнялся: его серверная положительная
и отрицательная ветки покрыты интеграционным тестом с другим явно
уполномоченным синтетическим actor. Реальные финансовые допуски не выдавались.
